# 2026-09-22

## 原型平台架构收敛：薄 Skill + npx CLI + 执行时更新 references（全资源在 GitHub）
- **决策**：放弃「薄引导 Skill + 运行时 resolve 版本化 Kit」双层结构，改为「薄 Skill（只含入口协议）+ npx CLI + 每次任务开始时 `references update`」。版本决策发生在 update 那一刻，不是每次使用那一刻。Kit Release/channel 在线解析降级为备选（不是分发理由，GitHub Release 一样能分发）。
- **update-on-invoke 语义**（`src/references-update.mjs`）：TTL 默认 60min 命中缓存直接返回；联网检查走 `channel-stable.json`（默认 repo `yanxlg/pen-antd-kit`，`PEN_ANTD_REPO` 可覆盖）；下载 tarball → 校验 SHA-256 → 原子装配到 `~/.pen-antd/kits/<version>/` → 返回 `kitRoot` + `skillPath`；失败降级本地 Kit 并返 `stale:true`+warning，无本地 Kit 才报错。
- CLI 用法：`--source <kit-root>`（需含 release.json，本地 Kit）/ `--channel-file`（本地或远程渠道）/ `--repo` / `--ttl` / `--force`。本地开发用 `--channel-file channels/development.json`（目录型 artifact 指向仓库根）。
- **发布**：Kit（含完整 Skill + references）走 GitHub Release，tag `kit-v*`；CLI 包 **`@pen-kit/antd`**（npm scope 与 GitHub owner 解耦，旧名 `@pen-kit/pen-antd` 已 deprecate）发公共 npm（`registry.npmjs.org`，`publishConfig.access=public`），tag `cli-v*`，发布脚本 `scripts/publish-cli.mjs`（dry-run 默认 + `--execute`，`--registry` 可切到 GitHub Packages/企业源），CI 模板 `publishing/github-actions/publish-cli.yml`（OIDC trusted publishing，无 secret；详见下方「发布 CLI 到公共 npm：已完成」）。
- 薄 Skill 中 CLI 一律走 `npx -y @pen-kit/pen-antd@latest ...`；公共 npm 免客户端配置（这是选公共源而非 GitHub Packages 的原因——Packages 连下载都要 PAT）。前提：npm 上 `@pen-kit` scope 可用且账号有发布权。Kit 的 GitHub repo 仍是 `yanxlg/pen-antd-kit`，与 npm scope 无关。
- 两处 SKILL.md：`pen-prototype-platform/skills/antd-prototype/SKILL.md`（bundle 版）order 第 1 步改 `references update`；`src/skill-bootstrap.mjs` 生成薄引导层。根目录 `skills/antd-prototype/`（组件库维护工作流）保持未动。
## 发布 CLI 到公共 npm：已完成
- 包名最终为 **`@pen-kit/antd`**（先用 `@pen-kit/pen-antd` 发了 0.1.0/0.1.1，后改名重发 0.1.1；旧名已 `npm deprecate` 指向新名，撤销用 `npm deprecate @pen-kit/pen-antd ""`）。`@pen-kit` scope 可直接发布，无需建 org。
- token 写在用户级 `~/.npmrc`（未进仓库任何文件）。旧 token 在对话里明文出现过一次，已换新 token 轮换。
- **2FA 已关闭**（用户操作），本地 `--execute` 不再报 EOTP；`scripts/publish-cli.mjs` 保留 `--otp` 透传备用。
- **CI 改用 npm Trusted publishing（OIDC）**，不再需要任何 secret：`publishing/github-actions/publish-cli.yml` 声明 `permissions.id-token: write`，node 24 + 发布前 `npm install -g npm@latest`（OIDC 要求 npm CLI >= 11.5.1、Node >= 22.14.0）。
- Trusted Publisher 只能在**包已存在后**配置：npmjs.com → `@pen-kit/pen-antd` → Settings → Trusted publishing → GitHub Actions，填 `yanxlg` / `pen-antd-kit` / workflow 文件名（复制模板后是 `publish-prototype-cli.yml`，文件名必须对得上）。Allowed actions 选 `npm publish`。配完可在 Publishing access 选「Require two-factor authentication and disallow tokens」关掉 token 通道。
- 端到端验证：`npx -y @pen-kit/pen-antd@latest references update` 能拉到 CLI 并执行；远程 Kit 尚未发布 → 404 → fallback 本地 Kit + `stale:true`，符合降级设计。
