## Search loading 卡 spinner 修复（path 抄错 + pen 不支持弧命令）
- 现象：官网 loading spinner 是一条**细圆弧**，我们渲成粗圆环/整圆描边。
- 根因：`Input.Search.js` 内联的 `LoadingOutlined` 是一条被改过的假路径（viewBox 64 64 896 896），不是官方数据。官方定义在 `canvas-components/icons/LoadingOutlined.js` / `node_modules/@ant-design/icons-svg`：viewBox `0 0 1024 1024`，是以 (512,512) 为圆心、半径 440~512 的 **90° 圆环 + 两端 r=36 圆头**（线宽 72/1024 ≈ 1px @14px，所以看起来是细弧）。
- 坑：**pen 的路径渲染不支持 `a`（椭圆弧）命令**，直接贴官方 d 只渲出一小段竖线。解法：用等价三次贝塞尔重绘（生成器 `/tmp/genring.js`，k=0.5523，仅 M/C/Z）：
  `M512 72C755.01 72 952 268.99 952 512C952 531.88 968.12 548 988 548C1007.88 548 1024 531.88 1024 512C1024 229.23 794.77 0 512 0C492.12 0 476 16.12 476 36C476 55.88 492.12 72 512 72Z`
- 校验：导出 8x 图，r1/r2 spinner 均为细圆弧（~7×8px 范围内 1~2px 粗），与官字形一致。
- 一般结论：给 canvas 组件内联官方图标时，必须抄 `canvas-components/icons/*.js` 里的 definition（仓库已有官方生成版），并且遇到 `a` 命令要先转贝塞尔。
