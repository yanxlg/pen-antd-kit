# Prototype invariants

- A prototype may be generated only after the required Pen library is available and verified.
- Existing Ant Design concepts use library component instances rather than hand-drawn substitutes.
- Templates accelerate composition but never override the actual information architecture or workflow.
- Every primary task includes relevant loading, empty, failure, validation, and success behavior.
- Product assumptions remain explicit and reversible.
- Prototype generation does not imply production UI code generation.
