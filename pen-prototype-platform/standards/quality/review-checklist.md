# 原型质量门禁

交付前逐项检查。任一硬失败存在时，原型不能标记为通过。

## 任务与结构

- [ ] 每个主要角色的目标都有可发现的完成路径。
- [ ] 页面外壳归属明确，没有重复宿主导航。
- [ ] 主行动唯一且层级清晰，次要行动不会争夺注意力。
- [ ] 页面模式与真实信息架构匹配，没有为了复用模板而扭曲流程。

## 组件与视觉

- [ ] Ant Design 已有概念使用当前 library 实例，而不是手绘替代。
- [ ] 间距、色彩、字号、圆角和状态优先使用 Kit token 与组件变体。
- [ ] 无重复卡片边框、双重内边距、偶然阴影或无意义装饰。
- [ ] 标题、说明、数据和行动的视觉层级在首屏可辨识。

## 内容与状态

- [ ] 展示初始加载、正常数据、查询空和请求失败。
- [ ] 涉及编辑时，展示校验失败、提交中、成功和保存失败。
- [ ] 长文本、长翻译、空值、`0`、`false` 和异常数据不会破坏布局或被误判为空。
- [ ] 所有截断值都有获得完整内容的路径。
- [ ] 没有 `Lorem ipsum`、未解释的占位符或与业务无关的演示数据。

## 操作、权限与恢复

- [ ] 未授权行动隐藏；暂不可用行动禁用且说明原因。
- [ ] 危险行动有与影响范围匹配的确认方式。
- [ ] loading 防止重复提交；失败后恢复可操作并保留必要上下文。
- [ ] 未保存修改、服务端冲突和刷新失败有恢复路径。

## 适配与可访问性

- [ ] 至少检查 1440px 桌面和 760px 窄视口；没有主行动被裁剪或意外重叠。
- [ ] RTL、长英文或乌尔都语不会破坏关键结构。
- [ ] 焦点可见，浮层关闭后回到触发点，错误可定位到首个字段。
- [ ] 图标有可访问名称，颜色不是唯一状态信号，Tooltip 不是唯一信息载体。

## 硬失败

以下任一项直接判定不通过：缺失主任务路径；已有 library 组件被手绘；危险操作无确认；完整值不可达；状态仅靠颜色；主行动被裁剪；存在未解决占位、断裂引用、重叠或溢出。
